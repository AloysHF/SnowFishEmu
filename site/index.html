什么是雪鲤鱼 / SFA 应用？

2000 年代中后期，上海的雪鲤鱼（SnowFish）平台向国产功能机提供可下载的手机应用：.app 二进制搭载在 ARM 芯片上运行，通过平台 API 绘制屏幕、读取文件、发起网络与付费请求——那个"KTV 手机小游戏"年代的记忆。

SnowFishEmu 在没有原厂服务器与运营商短信通道的今天，把这些应用重新跑起来：纯 Rust 的 ARMv4T CPU 内核执行来宾代码，服务桥逐槽位补齐平台行为，LZ 解压与平台位精确一致。

核心特性

从包格式到显示桥，每个层次都按平台行为逐项对齐。

🧩

SFA 包格式支持

头部解析、代码重定位、sfa_info 检查工具与姊妹资源文件的自动供给。

⚙️

ARM/Thumb CPU 内核

纯 Rust 的 ARMv4T 解释器，补全 ARMv5TE 行为（BLX 互通、DSP 乘法），无第三方 C 依赖。

🌉

平台服务桥

按包装分发点的平台 API 表：日志、来宾文件 I/O、UI 定时器与位精确的 LZ 流解压。

🎨

GDI 显示桥

240×320 RGB565 帧缓冲：区域填充、调色/RGB 位块（裁剪与色键透明）、CJK 文本渲染。

📴

离线启动与免付费

网络与付费查询本地应答，--free-play 把平台应答为已注册的计费手机，--offline-http 本地完成运营商事务。

🕹️

三种前端

桌面窗口、snowfishemu_libretro 核心（含 SFEMSTAT 存档状态）与浏览器 WebAssembly 核心。

快速开始

三条路径把 .app 应用跑起来：浏览器、桌面或 RetroArch。

1在线试玩

  1. 打开试玩页面，选择本机的 .app 文件（或拖入页面）。
  2. WebAssembly 核心随 EmulatorJS 自动加载，文件只在本地处理。
play.html  ←  选择 game.app

2桌面运行

  1. 从 Releases 下载独立版，或从源码构建：
cargo build --release -p snowfishemu
snowfishemu game.app --free-play --offline-http

3RetroArch 核心

  1. 把核心放入 RetroArch 的 cores/ 目录，info 文件放入 info/。
  2. 以 .app 为内容加载即可；方向键 + OK + 软键即是手机键盘。
cores/snowfishemu_libretro.dll
info/snowfishemu_libretro.info
